# 3Dトラック積載シミュレーター (3D Truck Loading Simulator)
### マルチ便管理（日次約100便対応）＆ 現場実務安全基準（OH 0cm厳守）準拠版

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Ready-brightgreen)](https://bth4077.github.io/3d-truck-loading-simulator/)
[![Three.js](https://img.shields.io/badge/Three.js-r128-blue)](https://threejs.org/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-v3-38bdf8)](https://tailwindcss.com/)

3D空間上でトラック（10tウイング車、4t中型、2t小型）およびパレット（1100mm / 2200mm）への段ボール・貨物混載パッキングをリアルタイムに計算・描画・検証できるWebアプリケーションです。
2024年問題への対策、パレタイズロボット導入検討、日次約100便に及ぶ幹線便の配車・積載調整を支援します。

## 🌟 主な機能・アップデート

### 1. OH（オーバーハング）現場安全基準の厳格化と品質リスク警告
- **実務背景**: 物流現場では、わずか数cmのオーバーハング（パレット枠外へのはみ出し）でも、ウイング開閉時や輸送振動で側壁・隣荷物に干渉し、荷傷み・外装潰れが発生します。到着先で荷傷みが発覚した場合、積込時のOHが原因であればドライバー様の荷役責任を問われるため、ドライバー様は原則受領拒絶（荷受け不可）となります。またストレッチフィルムの結束力低下による荷崩れリスクも伴います。
- **システム対応**:
  - デフォルト（標準値）を**「OH 0cm（完全枠内収まり・高さ215cm）」**に厳格化。
  - テスト等で OH > 0 または 高積み > 225cm が指定された場合は、画面上に「⚠️ 品質リスク警告（荷傷み・ドライバー荷役拒否リスクあり）」の赤色点滅バッジおよび警告トーストを常時明示。

### 2. 日次約100便対応の「マルチ便タブ管理＆全便集計」
日々の膨大な出荷・幹線便データをストレスなく切り替え、一瞬で積載状況・積み残しの有無を確認できるUI設計です。
- **便別タブバー（画面上部）**:
  - インポートした出荷リストから「幹線6511 [愛知RDC]」「幹線6512 [大阪メディカル]」などのタブを自動生成。
  - 各タブに「✅ OK（緑）」や「⚠️ 残Xcs（赤点滅）」のステータスバッジを表示し、調整が必要な便を一目で識別。
  - タブ検索フィルター機能により、目的の便を即座に絞り込み可能。
- **全便集計サマリービュー（一括ダッシュボード）**:
  - 全100便の「積載率・容積率・重量率・積み残しケース数」を一覧できる集計モーダルを搭載。
  - 「積み残し便のみ」「OK便のみ」のワンタッチ絞り込みに対応。
- **便間商品移動（回送・手修正機能）**:
  - 積み残しが発生した便から、スペースに余裕のある他便へ、特定商品を任意ケース数だけ振替・回送可能。
- **100便一括デモ生成機能**:
  - 全国15拠点（愛知、大阪、福岡、仙台、広島等）× 100便の実務データを1クリックで自動生成し、大規模運用の実務シミュレーションが可能。
- **全便統合JSON保存・読込**:
  - 単一便データだけでなく、日次100便すべての編成データをひとまとめに保存・復元可能。

### 3. パレタイズロボット想定の荷姿仕様
- **同一品種 下層優先配置（ボトムアップ層積み）**:
  - パレット床面（$Y=0$）から同一品種を敷き詰め、安定した土台を形成。
  - 品種が上下に細かく混ざるのを抑制し、ロボットのピッキング・層積みに最適化。
- **天面フラップラインの側面描画**:
  - 吸着に適した上向きを優先し、横倒し配置時は外側面側に天面フラップラインを描画。

### 4. 積み残し貨物のトラック外可視化 (Overflow Staging Area)
- 荷台から溢れた段ボールは、トラック後方ゲート外のステージングエリアに**赤色半透明＋赤色ワイヤーフレーム**で整列描画。
- 3Dモデルをクリックすると荷台内外のステータスバッジを表示。

## 🛠 使用技術
- **Three.js (r128)**: 3Dグラフィックス描画エンジン
- **OrbitControls**: 360度カメラ回転・パン・ズーム操作
- **Tailwind CSS (CDN)**: モダンでレスポンシブな現場UI
- **Lucide Icons**: SVGアイコン群
- **Pure JavaScript**: 高速な3Dパッキング計算・マルチ便管理（依存パッケージ不要）
